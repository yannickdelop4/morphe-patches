# Yannick's Morphe Patches

Private collection of independent custom patches for Android applications, built with the [Morphe Patcher](https://github.com/MorpheApp/morphe-patcher).

> **Development status:** experimental. Patches are not considered stable until their target app version, fingerprint matching, successful patching, and on-device behavior have been verified.

## Patch projects

### WetterOnline — remove Werbefrei promotional cards

- Package: `de.wetteronline.wetterapp`
- Analyzed version: `2026.22`
- Source: `patches/src/main/kotlin/app/yannick/patches/wetteronline/`
- Status: experimental / incomplete
- Known issue: the current patch builds and installs, but promotional cards remain visible in the tested app. Two confirmed call sites are in `Lcma;->invoke(...)` and `Lj97;->invoke(...)`. Both need handling, followed by verification that reserved layout space is removed.

No release is advertised as functional until this is resolved and tested.

## Development

This repository follows the Morphe patches template structure.

### Build locally

Run `./gradlew :patches:buildAndroid`. The generated `.mpp` bundle is written to `patches/build/libs/`.

Load the bundle into Morphe Desktop for local testing.

### GitHub Packages authentication

The Morphe Gradle plugin is retrieved from GitHub Packages. Authenticate with a GitHub token with the `read:packages` scope. Never commit the token to this repository.

```bash
gh auth refresh --hostname github.com --scopes read:packages
GITHUB_ACTOR="$(gh api user --jq .login)" \
GITHUB_TOKEN="$(gh auth token)" \
  ./gradlew :patches:buildAndroid
```

## Release process

The intended release flow uses the Morphe template's semantic-release GitHub Actions workflow. Generated files such as `patches-list.json`, `patches-bundle.json`, and `CHANGELOG.md` should be generated by that workflow, not maintained by hand.

The repository is private and intended for development and personal use. Morphe Manager patch sources need to be publicly accessible; this private repository is not currently a usable public source.
